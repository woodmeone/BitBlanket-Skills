# 关键词配置语法参考

配置文件：`config/frequency_words.txt`

## 文件结构

```text
[GLOBAL_FILTER]
# 全局过滤词

[WORD_GROUPS]
# 关键词配置
```

## 语法总览

| 语法 | 作用 | 示例 |
|------|------|------|
| 普通词 | 基础匹配 | `华为` |
| `/正则/` | 正则匹配 | `/华为|鸿蒙/` |
| `关键词 => 别名` | 显示别名 | `/华为|鸿蒙/ => 华为系` |
| `[组名]` | 词组别名 | `[科技巨头]` |
| `+关键词` | 必须包含 | `+苹果` `+发布会` |
| `!关键词` | 排除内容 | `!广告` |
| `@数字` | 限制条数 | `@10` |

## 基础用法

### 1. 普通关键词

```text
华为
```

匹配所有包含"华为"的新闻。

### 2. 多个关键词归为一组

```text
华为
鸿蒙
任正非
```

匹配包含"华为"或"鸿蒙"或"任正非"的新闻。

### 3. 给词组起名字

```text
[华为生态]
华为
鸿蒙
任正非
```

显示名称为"华为生态"。

## 高级用法

### 正则表达式

```text
/华为|鸿蒙|任正非/ => 华为系
```

- `/.../` 包裹正则表达式
- `|` 表示"或"
- `=> 别名` 设置显示名称

### 精确匹配英文单词

```text
/\bAI\b/ => AI
```

- `\b` 表示单词边界
- 避免匹配到 "MAIL" 中的 "AI"

### 排除特定内容

```text
[苹果公司]
苹果
!水果
!果园
```

匹配"苹果"但排除包含"水果"或"果园"的新闻。

### 限制显示条数

```text
[科技新闻]
科技
@5
```

最多显示 5 条匹配的新闻。

### 必须同时包含

```text
+苹果
+发布会
```

必须同时包含"苹果"和"发布会"才匹配。

## 全局过滤

```text
[GLOBAL_FILTER]
震惊
标题党
广告
营销
```

全局过滤词会排除所有包含这些词的新闻，优先级最高。

## 完整示例

```text
[GLOBAL_FILTER]
震惊
标题党
广告

[WORD_GROUPS]

# 科技公司
/深度求索|幻方量化|DeepSeek/ => DeepSeek

/华为|任正非|余承东|鸿蒙|海思/ => 华为

/比亚迪|王传福|刀片电池|云辇/ => 比亚迪

# AI 相关
[AI 相关]
/\bai\b/
人工智能
ChatGPT

# 芯片半导体
[芯片]
芯片
光刻机
半导体
@5

# 排除特定内容
[苹果公司]
苹果
!水果
!果园
```

## 显示名称优先级

1. 有组别名 → 显示组别名
2. 没有组别名 → 显示各行别名拼接（用 " / " 连接）
3. 没有别名 → 显示关键词本身
