# 账号定位关键词模板参考

本文档提供常见账号定位的关键词配置模板，供快速配置使用。

## 使用方法

```powershell
# 使用预设定位模板
python scripts/config_keywords.py --positioning "AI实战成长博主"

# 查看所有可用定位
python scripts/config_keywords.py --list

# 自定义关键词
python scripts/config_keywords.py --keywords "AI,ChatGPT,DeepSeek,开源"
```

## 预设定位模板

### 1. AI实战成长博主

**定位描述**：专注分享AI工具使用教程、开源项目实战，目标受众：想学习AI应用的开发者和职场人

**关键词覆盖**：
- AI工具与模型：AI、ChatGPT、Claude、DeepSeek、Midjourney等
- AI应用场景：AI工具、AI办公、AI写作、RAG、Agent
- 开源项目：GitHub开源、LLM、微调、部署
- 科技公司动态：华为、苹果、特斯拉、字节、阿里、腾讯

### 2. 科技数码博主

**定位描述**：分享数码产品评测、科技资讯、新品发布，目标受众：科技爱好者

**关键词覆盖**：
- 手机数码：iPhone、华为、小米、OPPO、三星
- 电脑硬件：显卡、CPU、内存、笔记本
- 科技公司：苹果、微软、谷歌

### 3. 财经投资博主

**定位描述**：分享投资理财知识、市场分析、财经资讯，目标受众：投资者和理财人群

**关键词覆盖**：
- A股市场：A股、股市、涨停、大盘
- 行业板块：新能源、半导体、AI概念、医药
- 宏观经济：美联储、利率、通胀、GDP
- 财经资讯源：华尔街见闻、财联社

### 4. 职场成长博主

**定位描述**：分享职场技能、职业发展、效率提升，目标受众：职场人士

**关键词覆盖**：
- 职场技能：面试、简历、升职、跳槽
- 效率工具：Notion、Excel、时间管理
- 职业发展：职业规划、副业、远程办公

### 5. 编程技术博主

**定位描述**：分享编程技术、开发教程、技术趋势，目标受众：开发者

**关键词覆盖**：
- 编程语言：Python、JavaScript、Java、Go、Rust
- 前端技术：React、Vue、CSS
- 后端技术：微服务、数据库、Docker
- 开发工具：VSCode、Git、GitHub

### 6. 自媒体运营博主

**定位描述**：分享自媒体运营技巧、平台规则、变现方法，目标受众：内容创作者

**关键词覆盖**：
- 平台运营：抖音、小红书、B站、公众号、知乎
- 运营技巧：流量、粉丝、变现、爆款
- 内容创作：文案、剪辑、封面、标题

## 自定义关键词语法

### 基础语法

| 语法 | 作用 | 示例 |
|------|------|------|
| 普通词 | 基础匹配 | `华为` |
| `/正则/` | 正则匹配 | `/华为\|鸿蒙/` |
| `关键词 => 别名` | 显示别名 | `/华为\|鸿蒙/ => 华为系` |
| `[组名]` | 词组别名 | `[科技巨头]` |
| `+关键词` | 必须包含 | `+苹果 +发布会` |
| `!关键词` | 排除内容 | `!广告` |
| `@数字` | 限制条数 | `@10` |

### 完整配置示例

```text
[GLOBAL_FILTER]
震惊
标题党
广告

[WORD_GROUPS]

# AI 工具与模型
/\bai\b|人工智能|机器学习/ => AI技术
/ChatGPT|GPT-4|OpenAI/ => 大语言模型
/DeepSeek|深度求索/ => DeepSeek

# 限制显示条数
[芯片]
芯片
光刻机
@5

# 排除特定内容
[苹果公司]
苹果
!水果
!果园
```

## 扩展定位模板

如需添加新的定位模板，编辑 `scripts/config_keywords.py` 中的 `POSITIONING_KEYWORDS_MAP` 字典。

### 添加新模板示例

```python
POSITIONING_KEYWORDS_MAP["新定位名称"] = {
    "description": "定位描述",
    "keywords": [
        "[GLOBAL_FILTER]",
        "震惊",
        "",
        "[WORD_GROUPS]",
        "",
        "# 分类标题",
        "关键词1",
        "关键词2",
        "/正则表达式/ => 别名",
    ]
}
```
